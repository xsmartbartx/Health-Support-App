# SECURITY

Jeśli znalazłeś podatność, prosimy o odpowiedzialne zgłoszenie.

Kontakt (przykład): security@localhost

Zgłoszenie powinno zawierać:
- Krótki opis problemu i kroki reprodukcji
- Potencjalny wpływ i zasięg
- Proponowane rozwiązanie (jeśli dostępne)

W odpowiedzi potwierdzimy przyjęcie zgłoszenia i plan działań.
