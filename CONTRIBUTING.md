# Contributing

Dziękujemy za zainteresowanie kontrybuowaniem!

Jak zgłosić zmiany:
1. Forkuj repozytorium
2. Stwórz branch feature/<nazwa>
3. Uruchom testy i sprawdź lint
4. Otwórz PR opisując zmiany, testy i wpływ

Przed mergem:
- CI musi przejść
- Dwa review od maintainerów (opcjonalnie więcej dla krytycznych zmian)

Więcej: .github/PULL_REQUEST_TEMPLATE
